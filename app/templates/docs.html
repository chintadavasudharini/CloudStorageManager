Quickstart & Installation

CloudStorageManager is designed to run locally, on an EC2 instance, or containerized on AWS App Runner with minimal prerequisites.

1. Clone & Set Up Environment
git clone https://github.com/chintadavasudharini/CloudStorageManager.git
cd CloudStorageManager
python -m venv venv
.\venv\Scripts\activate # Linux/macOS: source venv/bin/activate
2. Install Dependencies
pip install -r requirements.txt
3. Run the Development Server
python run.py

Navigate to http://localhost:5000 in your web browser. By default, the application runs in Demo Mode with mock sample data ready for testing.

Architecture

Architecture Overview

The application is built on a clean three-tier model:

Tier Technology Purpose
Presentation Layer Bootstrap 5, Jinja2, Vanilla JavaScript Responsive web dashboard with drag-and-drop file upload, folder navigation, and instant search filter.
Application Layer Flask, Python 3.14 Handles route orchestration, session security, REST API responses, and streaming proxy downloads.
Cloud Storage Layer Boto3 AWS SDK, Amazon S3, Moto Direct integration with AWS S3 APIs or Moto mock engine using SigV4 signed operations.

Presigned URL Mechanics

An Amazon S3 presigned URL gives third-party consumers temporary access to an object without requiring them to have AWS IAM permissions or knowledge of access keys.

How it works behind the scenes:
  1. The client requests a shareable link for an object in a private bucket, specifying a time-to-live (e.g. 3600 seconds).
  2. The Flask backend calculates an HMAC-SHA256 signature using the active IAM Secret Access Key, your region, and the expiration timestamp.
  3. The URL query parameters encode: X-Amz-Algorithm, X-Amz-Credential, X-Amz-Date, X-Amz-Expires, and X-Amz-Signature.
  4. The recipient downloads the file directly from AWS S3. Once the time expires, AWS automatically refuses the link with a 403 Request has expired error.
Python Boto3 Implementation Snippet:
url = s3_client.generate_presigned_url(
    ClientMethod='get_object',
    Params={'Bucket': 'my-bucket', 'Key': 'reports/annual.pdf'},
    ExpiresIn=3600  # Link valid for 1 hour
)
IAM

IAM Policy & Least Privilege

Following the Principle of Least Privilege (PoLP), your IAM User should not have AdministratorAccess. Instead, attach the following tailored policy: 

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AllowBucketListing",
      "Effect": "Allow",
      "Action": [
        "s3:ListAllMyBuckets",
        "s3:GetBucketLocation"
      ],
      "Resource": "*"
    },
    {
      "Sid": "AllowObjectOperations",
      "Effect": "Allow",
      "Action": [
        "s3:ListBucket",
        "s3:GetObject",
        "s3:PutObject",
        "s3:DeleteObject"
      ],
      "Resource": [
        "arn:aws:s3:::*",
        "arn:aws:s3:::*/*"
      ]
    }
  ]
}
API

REST API Reference

All endpoints return JSON responses.

Endpoint Method Parameters Description
/api/upload POST bucket, prefix, file (multipart) Uploads file object to target S3 prefix with automatic MIME detection.
/api/presigned-url POST bucket, key, expiration (seconds) Generates cryptographically signed ephemeral download/upload URL.
/api/delete POST bucket, key Permanently deletes designated S3 object.
/api/create-bucket POST bucket_name, region Provisions a new globally unique S3 bucket in designated AWS region.
/api/create-folder POST bucket, prefix, folder_name Creates virtual directory marker in S3 bucket.
/api/metadata GET bucket, key Retrieves object headers: ETag, size, content-type, storage class.
Testing

Local Moto Mock S3 Engine

When ENABLE_DEMO_MODE=true or no AWS access keys are supplied, CloudStorageManager automatically instantiates a local in-memory Moto S3 mock server with pre-populated sample buckets and mock files.

To run the complete automated test suite:

python -m pytest tests -v
